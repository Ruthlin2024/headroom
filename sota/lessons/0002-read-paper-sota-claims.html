第 2 课：如何读论文里的 SOTA 声明

从 abstract 到实验表格 · 约 15 分钟

阅读顺序（不要从结论倒推）

  1. Abstract — 圈出所有 SOTA / outperform / state-of-the-art 字样
  2. 实验设置 — 用的哪个 benchmark？metric 怎么算？
  3. 对比表格 — baseline 是谁？是否公平（同数据、同算力、同 prompt）？
  4. 提升幅度 — 0.3 分在 100 分制里有意义吗？有误差条/多次 run 吗？
Abstract 里的 SOTA 是主张；Table 2 才是证据。你的工作是检查二者是否匹配。

表格里要看的 5 列信息

  • Method / Model name
  • Benchmark subset（如 MMLU 全量还是子集）
  • Metric 数值
  • Baseline 来源（同期公开模型还是作者复现）
  • 是否 bold 最佳 — bold 只表示该列最高，不表示全面胜利

红旗信号 🚩

  • 只比「自家上一版」或弱 baseline
  • 测试集与训练集有泄漏嫌疑
  • 未报告 variance / 单次 run
  • 「SOTA on average」但多数子任务输给别人
