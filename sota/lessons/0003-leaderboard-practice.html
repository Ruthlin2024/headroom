第 3 课：Leaderboard 实操

Papers with Code · 约 10 分钟

为什么要查 leaderboard？

论文里的 SOTA 是发表时刻的快照；公开 leaderboard 帮你回答： 「现在谁在第一？这篇论文还准吗？」

入口：paperswithcode.com

四步实操

  1. 搜任务 — 如 "question answering"、"image classification"
  2. 点进 benchmark — 看清 dataset 版本（如 ImageNet vs ImageNet-V2）
  3. 看 metric 列 — Top-1 accuracy？mAP？不同列榜一可能不同
  4. 点第一名论文 — 读 code 是否开源、设置是否可复现
榜一经常变。记录查询日期，例如：「截至 2026-06，MMLU 榜一为 …」

动手作业

任选一个你关心的 AI 任务，在 Papers with Code 填这张表（可写在 NOTES.md）：

  • Metric：
  • 当前榜一模型：
  • 查询日期：
